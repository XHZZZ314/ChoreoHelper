# 发布包安装与备份说明（属主中文）

> 版本：插件 0.7.1（程序集 0.7.1.0）。本说明随「发布收口 P2」Phase A（2026-09-27，离线）编写；
> 安装包本身（网页 zip＋插件 zip＋清单＋校验和）要等游戏开着现场出包（Phase B）后才有，
> 在此之前请勿把任何文件当作正式发布包散发。

## 一、两个包各是干什么的

- **网页包（必装）**：解压到任意文件夹，双击里面的 `choreo-helper-app.html` 就能用。
  编排动作时间轴、用 3D 替身排练，不需要开游戏。
- **插件包（可选）**：游戏内预览、录制动作才需要。前提是 FF14 国服＋橙月启动器
  （XIVLauncherCN）＋已装 Dalamud。

所有数据（动作库、模型、编舞草稿）只存在你自己的电脑浏览器里，没有账号，不上传云端。

## 二、安装步骤

### 网页包

1. 解压到任意文件夹（例如 `D:\choreohelper-web\`）。
2. 双击 `choreo-helper-app.html`。日常入口就是这个文件，可以建桌面快捷方式。
3. 首次打开约半分钟：动作目录、参考骨架会自动就绪（共 305 个动作、101 骨参考、
   内置替身模型），之后离线也能用。

### 插件包

1. 解压后把 `ChoreoHelper` 整个文件夹放进 `%AppData%\XIVLauncherCN\devPlugins\`。
   注意是整个文件夹，不是只拷 DLL——网页文件（`dist\ChoreoHelper\`）也在里面，
   只拷 DLL 会导致网页入口缺失。
2. 游戏内 `/xlsettings` → 实验性 → 打开 DevMode，并在 Dev Plugin Locations 里登记
   （指向 `ChoreoHelper\ChoreoHelper.dll`），重启游戏。
3. `/xlplugins` 里启用 ChoreoHelper。

### 配对（网页控制游戏前）

1. 游戏里输入 `/choreo pair`，会显示一串配对码（源码已恢复该命令；游戏内实际
   显示效果尚未验证，第一次用时请留意聊天栏输出）。
2. 在网页里按提示填入配对码。配对码只存在本机，不会进任何发布包。

## 三、升级

1. 先按第四节做一次备份（资料库＋项目各导一份）。
2. 新包解压覆盖旧文件夹即可。配置文件与浏览器里的数据不受影响。
3. 覆盖后双击打开一次网页，确认项目和动作都在，再删旧备份（建议保留一份）。

## 四、备份与恢复（已在 P2 演练中验证过）

### 备份（两份都要导）

- **资料库备份**：打开网页 → 舞者行「人物资源」→「📤 导出备份」，
  得到 `choreo-library-年月日.choreolib`（动作/骨架/模型/目录全在里面）。
- **项目备份**：工具栏「📁 项目」→ 展开「导入导出」→「导出」，
  得到 `choreo_时间戳.json`（当前项目的编排与引用；历史版本、人物、动作、
  音乐文件不在里面，要另行留好）。

把这两个文件拷到 U 盘或另一台电脑即完成备份。

### 恢复（换浏览器/换电脑/清空后）

- **项目恢复**：「📁 项目」→「导入导出」→「导入为新项目」→ 选择之前导出的
  `choreo_*.json`。会作为独立新项目（原名＋“副本”）导入，原项目保留。
- **资料库恢复**：「人物资源」→「📥 导入备份」→ 选择 `.choreolib` 文件，
  校验通过后自动恢复（演练中导出前后统计完全一致）。

### 自动保存与异常退出

- 编辑时浏览器会自动保存（最新内容在 `choreo_autosave` 镜像里）。
- 浏览器被强行关闭后重开，最新内容会自动回来，并留一个「异常关闭自动恢复」
  版本（已用强杀演练验证）。
- 旧格式草稿（`choreo_draft`）第一次打开时会自动迁成项目，原数据逐字节备份在
  `choreo_draft_backup_20260829`，原键不动，可重复打开不重复迁移。

## 五、离线使用

- 日常 file:// 入口（双击本地 html）完全离线可用：动作目录、骨架、替身都来自
  内置快照，不连游戏。
- 真模型：用 Meddle 导出 glTF（`model.gltf`＋`model.bin`），放进网页目录刷新即用；
  在线用过后会自动缓存进本地资料库，之后关游戏也能用。
- 注意：换浏览器、或将来搬到 HTTPS 官网后，file:// 下的 IndexedDB 数据不会自动
  过去，届时用第四节的备份/恢复搬一次。

## 六、故障排查

| 现象 | 处理 |
|---|---|
| 双击后动作列表是空的 | 等半分钟让快照加载；仍空则看浏览器控制台有无报错后反馈 |
| 网页打不开/白屏 | 确认解压完整（`libs-classic` 等目录缺一不可），重新完整解压 |
| 提示安装不完整 | 插件包只拷了 DLL：重新把整个 `ChoreoHelper` 文件夹放进 devPlugins |
| 配对码输完连不上 | 先确认游戏里 `/choreo pair` 能显示出码；游戏没开时网页编排与 3D 不受影响 |
| 录制/预览要游戏 | 这是正常的：录制与游戏内预览必须开着游戏＋插件；纯编排不需要 |
| 升级后项目不见了 | 用第四节的备份重新导入；旧草稿会自动迁移并留备份键 |

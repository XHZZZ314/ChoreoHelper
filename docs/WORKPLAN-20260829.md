# ChoreoHelper Follow-up Work Packages (2026-08-29)

> Construction order for future AIs. Do one work package at a time; do not start a package that depends on a previous one until that one meets its exit criteria.

## Common Definition of Done

Every work package must:

1. Check `git status --short` before modifying; preserve all pre-existing uncommitted changes.
2. Read the sources listed in this package plus the latest handoff; record the current baseline.
3. Change only this package's scope; add the corresponding regression tests.
4. Run the narrow tests and required overall acceptance; explicitly leave un-run on-device items to the owner.
5. Review the diff, deployed build artifacts, and private assets.
6. Update `.agent/CONTINUITY.md`; no commit, push, or release without the owner's authorization.

## WP-6: v0.8 Music, Beats, Stage, and Path Editing

**Dependency: WP-5.**

2. Stage origin, 2D top view, start points, facing, straight/curved paths, in-game manual path recording, and path simplification.

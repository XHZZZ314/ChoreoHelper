# ChoreoHelper 编舞助手

最终幻想XIV（国服客户端）演出编舞助手：**网页端离线编排 + 游戏内 Dalamud 插件**。

- **网页应用**（`web/`）：离线编排动作、技能、移动路线、朝向、歌词、节拍与舞台提示，内置 Three.js 3D 排练预览；支持从游戏内插件同步动作目录与骨骼快照。
- **游戏内插件**（`src/`）：C# / .NET 10 / Dalamud 插件，读取游戏动作数据、录制骨骼动作、游戏内预览，并按一份玩家手动启动的演出脚本执行（带紧急停止与手动接管，无挂机循环、无战斗决策）。

## 目录

| 目录 | 内容 |
| --- | --- |
| `src/` | 插件源码（`src/Exporter/` 录制导出模块，`src/tests/` 数据层测试） |
| `web/` | 网页源码（`web/dist/ChoreoHelper/` 为部署源） |
| `docs/` | 设计文档、路线图与历史交付记录 |
| `scripts/` | 构建与验证工具脚本 |
| `site/` | 早期官网页面备份 |

老版官网见 <https://xhzzz314.github.io/>。
